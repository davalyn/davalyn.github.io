4.1.3 Scatterplot of the raw data

I create a scatterplot to visualise the relationship between chemical concentration and the number of offspring. Different colours represent the chemicals, while different shapes represent the experimental conditions.

data$compConcentration <- as.numeric(data$compConcentration)

ggplot(data, aes(
  x = compConcentration, y = RawData,
  colour = compName, shape = expType)) +
  geom_point(position = position_jitter(width = 0.1, height = 0.5), alpha = 0.7) +
  scale_x_log10() +
  labs(x = "Concentration (log10)", y = "RawData",
       colour = "Chemical", shape = "Experiment type") +
  theme_bw()

4.1.4 Data normalisation

I normalise the data using the mean of the negative control. This makes the mean value of the negative control equal to 1, expressing all other measurements as a fraction of this value.

negative_mean <- mean(data$RawData[data$expType == "controlNegative"], na.rm = TRUE)

data$normalised <- data$RawData / negative_mean

mean(data$normalised[data$expType == "controlNegative"], na.rm = TRUE)
## [1] 1

4.1.5 Scatterplot of the normalised data

I create a second scatterplot to visualise the normalised measurements.

ggplot(data, aes(x = compConcentration, y = normalised,
                 colour = compName, shape = expType)) +
  geom_point(position = position_jitter(width = 0.1, height = 0.01), alpha = 0.7) +
  scale_x_log10() +
  labs(x = "Concentration (log10)", y = "Normalised RawData",
       colour = "Chemical", shape = "Experiment type") +
  theme_bw()

4.1.6 Explanation of the analysis

  • The negative control in this experiment is S-medium without added chemicals. This serves as a baseline to measure normal reproduction. The positive control is ethanol and is used to check whether the experiment can detect a particular effect.

  • The negative control represents the normal situation. The positive control demonstrates whether the experiment can detect an effect. The vehicle control checks whether the solvent itself influences the results.

  • Normalisation ensures that the mean of the negative control equals 1. This allows all other measurements to be compared fairly with the normal situation.

4.2 Assessing reproducibility

4.2.1 Article

Marinos et al. (2020). Defining the nutritional input for genome-scale metabolic models: A roadmap.

Article | GitHub repository

4.2.2 Research question

How can the nutritional composition of a growth medium be accurately translated into input data for genome-scale metabolic models?

4.2.3 Methods and results

The researchers developed a roadmap using E. coli and LB medium. They used R to analyse the nutritional composition and predict bacterial growth. The results show that different nutrients, such as amino acids and carbohydrates, influence the predicted growth.

4.2.5 Reviewing the R code

Code description

The R code uses a metabolic model of E. coli to investigate how nutrients influence predicted bacterial growth. Flux Balance Analysis is used for this purpose. The code calculates the effects of additional nutrients and visualises the results using bar plots.

Readability

Score: 3/5

The code contains clear comments and is organised into sections. However, some functions and calculations are too complex for me to fully understand. I also had to adjust the file paths several times.

Reproducibility

Score: 2/5

I attempted to run the analysis in RStudio, but encountered installation problems with glpkAPI. As a result, I was unable to reproduce the figures. Although the code and data are publicly available, the analysis requires adjustments before it can be executed successfully.
