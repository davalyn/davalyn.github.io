# Portfolio DSFB2

Deze repository bevat mijn portfolio voor de opleiding Data Science for Biology 2 (DSFB2).

## Inhoud

De repository bevat de volgende onderdelen:

- `index.Rmd`: de startpagina van het portfolio.
- `1a_CV.Rmd`: curriculum vitae.
- `1b_Toekomstplan.Rmd`: toekomstplan.
- `2_Vrije_opdracht.Rmd`: vrije opdracht.
- `3a_RNA-seq_DAUR2.Rmd`: data management van het RNA-seq-project.
- `3b_Portfolio_repository.Rmd`: data management van de portfolio repository.
- `4a_Analyse_reproduceren.Rmd`: analyse reproduceren.
- `4b_Reproduceerbaarheid_beoordelen.Rmd`: reproduceerbaarheid beoordelen.
- `5_SQL.Rmd`: SQL-opdracht.
- `6_R_package.Rmd`: R-package-opdracht.

## Mappenstructuur

- `data/`: voor databestanden.
- `code/`: voor losse R-scripts.
- `images/`: voor afbeeldingen.
- `_book/`: gegenereerde Bookdown-website.
- `libs/`: ondersteunende bestanden voor de HTML-website.

## Data management

- Bestanden worden logisch georganiseerd in aparte mappen.
- Bestandsnamen zijn duidelijk en herkenbaar.
- De R Markdown-hoofdstukken blijven in de hoofdmap voor Bookdown.
- Git wordt gebruikt voor versiebeheer van de repository.
